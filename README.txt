车卜卜官网 V1 上传步骤

1. 打开 GitHub 仓库 privacy-policy。
2. 点击“添加文件 / Add file”→“上传文件 / Upload files”。
3. 上传 index.html 和 privacy-policy.html。
4. 选择直接提交到 main 分支，然后点击 Commit changes。
5. 等待 1—5 分钟，刷新 https://chebubuauto.com。

启用 WhatsApp：
打开 index.html，搜索：const WHATSAPP_NUMBER="";
把国际区号和号码填入引号内，例如：const WHATSAPP_NUMBER="8613812345678";
不要加 +、空格或横线。
